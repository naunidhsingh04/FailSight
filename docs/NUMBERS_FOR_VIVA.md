## Things to say if asked

* The best model on any list was chosen on the test set, so its lead is optimistic; the ranges overlap.
* Run identification can reproduce the AnoMod scores (proof P14), so they are not proof of fault detection.
* LO2 is training on LO2's own data, a very small sample; no transfer claim.
* FailSight notices a problem that has started; it cannot forecast a failure, and time-until-failure is future work (not built).
